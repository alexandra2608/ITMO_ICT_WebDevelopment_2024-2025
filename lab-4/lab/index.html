    Vue.js

    Реализация клиентской части приложения средствами Vue.js

    Реализовать клиентскую часть сайта, используя фреймворк Vue.js, в соответствии с вариантом задания лабораторной работы.

    Вариант: система обмена рецептами

    1. Настроить для серверной части, реализованной в лабораторной работе №3 CORS (Cross-origin resource sharing).
    2. Утвердить с одним из преподавателей список интерфейсов для взаимодействия с серверной частью в соответствии с вашей предметной областью.
    3. Реализовать интерфейсы авторизации, регистрации и изменения учётных данных и настроить взаимодействие с серверной частью.
    4. Реализовать клиентские интерфейсы и настроить взаимодействие с серверной частью.
    5. Подключить vuetify или аналогичную библиотеку.

    Настройка CORS

    После установки django-cors-headers он был добавлен в файл settings.py:

    INSTALLED_APPS = (
    ##...
    'corsheaders'
)

    Затем corsheaders.middleware.CorsMiddleware был добавлен в “MIDDLEWARE_CLASSES” в settings.py и CORS был включен для всех доменов:

    MIDDLEWARE_CLASSES = (
    'corsheaders.middleware.CorsMiddleware',
    'django.middleware.common.BrokenLinkEmailsMiddleware',
    'django.middleware.common.CommonMiddleware',
    #...
)

    CORS_ORIGIN_ALLOW_ALL = True

    Настройка взаимодействия с сервером

    После старта vue-проекта в файле api/instance.js была прописана ссылка на серверную часть const apiURL = 'http://127.0.0.1:8000', которая затем использовалась в каждом компоненте с дописанным соответствующим эндпоинтом в формате:

    import instance from "@/api/instance";

try {
    await instance.post("/auth/users/", {
      username: formData.value.username,
      email: formData.value.email,
      password: formData.value.password,
    });
}

    Здесь приведен пример отправки POST-запроса на сервер с клиента при регистрации нового пользователя.

    Роутинг

    Для каждого написанного компонента в файле роутера router/index.js была прописана ссылка в формате:

    import { createRouter, createWebHistory } from 'vue-router'
import Profile from "@/views/Profile.vue";
const router = createRouter({
 history: createWebHistory(import.meta.env.BASE_URL),
 routes: [
    {
     path: '/profile',
     name: 'Profile',
     component: Profile,
     meta: { requiresAuth: true },
   },
   ],
})

router.beforeEach((to, from, next) => {
 const token = localStorage.getItem("auth_token");
 if (to.matched.some(record => record.meta.requiresAuth) && !token) {
   next({ name: 'Login' });
 } else {
   next();
 }
});

export default router

    В данном листинге продемонстрирован защищенный роутинг, примененный к компоненту профиля пользователя: на эту страницу может перейти только авторизованный пользователь.

    Компоненты

    Деление на компоненты по окончании работы оказалось следующим:

    Было создано 3 представления для основных страниц приложения – главная, страница рецепта и профиль пользователя. В каждом из них были перечислены используемые компоненты, разложенные по соответствующим папкам. Также были созданы компоненты регистрации и авторизации, шапка сайта, модальное окно, добавление рецепта на сайт, редактирование рецепта.
